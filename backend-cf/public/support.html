支持

怎么开始用?

见首页的上手指南:手机装 App 输邀请码,Mac 装 pkg 跑 sessionbell pair,共四步。邀请码问邀请你的人要。

App 里看不到任务 / 显示连不上?

打开 设置 → 接入 → 测试连接。绿色 ✅ 说明手机侧正常,问题在 Mac:确认 pkg 装过、配对命令跑过、Mac 弹出的权限框都点了允许。红色 ❌ 会写明原因,把它截图发给我们即可。

锁屏卡片不出现?

iOS 对锁屏卡有系统级频率限制,短时间反复测试会被静默丢弃。打开 App → 设置 → 唤起锁屏面板手动拉起,之后它会随任务自动更新。

通知太吵 / 收不到?

SessionBell 有空闲检测:你在 Mac 前打字时不会推送。收不到时检查 iPhone 设置 → 通知 → SessionBell 已允许,且没开专注模式拦截。

Windows 能用吗?

可以(beta)。在 iPhone 上拷贝配对命令后,PowerShell 里运行 irm https://sessionbell.westie.ai/install.ps1 | iex 即可。通知、锁屏卡片、手机批准、用量统计、终端模式(远程看屏/输入)都可用;claude 跑在 WSL 里的场景终端模式暂不覆盖。

想自己部署后端?

完全支持。项目 MIT 开源,后端是一个 Cloudflare Worker,一条命令部署:见 GitHub 仓库的 Self-hosted 一节。

怎么删除我的数据?

发邮件告诉我们你的配对码前 8 位(或直接换个说法描述你是谁),我们清空对应命名空间。详见隐私政策。
